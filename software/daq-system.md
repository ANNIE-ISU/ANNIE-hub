## What This Is

The ANNIE Data Acquisition (DAQ) system reads out detector signals, applies triggering logic, and writes data to disk. ANNIE uses the **ToolDAQ** framework.

## ToolDAQ

ToolDAQ is a modular, tool-based framework developed for ANNIE. Each processing step is a "Tool" that can be chained together into a "ToolChain."
