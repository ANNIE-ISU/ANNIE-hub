# ANNIE-Hub

Shared knowledge base and project management hub for the **ANNIE (Accelerator Neutrino Neutron Interaction Experiment)** group at Iowa State University.

## What this repo is

This is not a code repository. It is a **living wiki** — a structured, version-controlled knowledge base for the entire ANNIE ISU group. It is designed to be readable and useful both for human collaborators and AI agents (Claude, Copilot, etc.).

## Where to start

→ **[INDEX.md](INDEX.md)** — the master map of everything in this wiki.

## Structure

```
ANNIE-hub/
├── INDEX.md              ← start here
├── detector/             ← hardware and physical systems
├── physics/              ← science goals and signal/background
├── software/             ← DAQ, simulation, analysis tools
├── projects/             ← active threads, decisions, completed work
├── people/               ← who is working on what
└── meetings/             ← notes and action items
```

## Contributing

See [CONTRIBUTING.md](.github/CONTRIBUTING.md). The short version: keep entries atomic, keep links updated, and add a decision log entry whenever the group makes a significant choice.
