## What This Is

Every significant technical or strategic decision the group makes should have an entry here. This is one of the highest-value parts of the wiki — it prevents the group from relitigating past decisions and gives new members (and AI agents) context on *why* things are the way they are.

## How to Add an Entry

Create a new file in this folder named `YYYY-MM-DD-short-description.md` using the template below.

## Template

```markdown
# Decision: [Short Title]

**Date:** YYYY-MM-DD  
**Made by:** [names / meeting]  
**Status:** Decided / Revisited / Superseded by [link]

## Context
What was the situation that required a decision?

## Options Considered
- Option A: ...
- Option B: ...

## Decision
What was decided and why.

## Consequences
What this decision means going forward. What trade-offs were accepted.
```
