# ANNIE-Hub: Master Index

**Purpose:** This is the primary entry point for all AI agents and human collaborators working on the ANNIE experiment at Iowa State University. Start here. Every article in this knowledge base is reachable from this index.

**Last updated:** 2026-10-26  
**Maintained by:** ANNIE ISU Group (PI: Matt Wetstein, wetstein@iastate.edu)

## How to Use This Wiki

- **AI agents:** Load this file first. Follow links to domain articles for deep context. Decision logs explain *why* choices were made.
- **Humans:** This is your map. Every research thread, system, and concept has a home here. Add to it when you learn something worth keeping.
- **Contributing:** See [CONTRIBUTING.md](.github/CONTRIBUTING.md) for conventions.
